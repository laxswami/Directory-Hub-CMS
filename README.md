# 📖 Overview

**Directory Hub** is a powerful **Business Directory Script** built using **PHP** and the **Laravel Framework**.

Inspired by platforms like **Yelp**, **Yellow Pages**, and modern business listing websites, Directory Hub enables you to create professional directory portals with business listings, products, classifieds, custom fields, unlimited categories, multi-country support, and much more.

Whether you're building a:

- 🏢 Business Directory
- 🌎 Local City Guide
- 🛍 Marketplace
- 📦 Product Directory
- 🔧 Service Directory
- 🏥 Medical Directory
- 🎓 Educational Portal
- 🍽 Restaurant Listing
- 🏨 Hotel Directory
- 🚗 Automobile Directory

Directory Hub provides everything you need.
